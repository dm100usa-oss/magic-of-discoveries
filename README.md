# Magic of Discoveries — основа нового сайта

Каркас нового официального сайта для домена magicofdiscoveries.com.
Собран на Next.js, рассчитан на бесплатный тариф Vercel.

## Что уже работает

- 28 отдельных страниц книг: 14 английских и 14 испанских
- Каталог с фильтрами по возрасту и типу книги
- Главная с тремя блоками и реальными отзывами со старого сайта
- Страницы «О нас» и «Контакты»
- Раздел бесплатных раскрасок: структура готова, наполнение пустое
- Оформление, перенесенное со старого сайта на Wix
- Карта сайта, robots.txt с разрешением для сборщиков нейросетей, llms.txt
- Разметка Book, Offer и FAQ на каждой странице книги
- Языковые связи между английским и испанским изданием

## Куда что класть

- Каталог книг: `src/data/books.ts`. Добавить книгу = добавить одну запись.
- Тексты интерфейса: `src/data/dictionaries.ts`. Русский уже написан, включится сам.
- Бесплатные раскраски: `src/data/coloringPages.ts` плюс файлы в `public/printables/`.
- Обложки: `public/covers/`. Пока пусто, на их месте выводится название книги.

## Как запустить

    npm install
    npm run dev

## Как выложить на Vercel

Загрузить папку в новый репозиторий на GitHub, в Vercel нажать Import,
никаких настроек менять не нужно. Домен подключается позже.
