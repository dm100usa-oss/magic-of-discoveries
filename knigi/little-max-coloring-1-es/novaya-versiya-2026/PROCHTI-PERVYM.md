# Pequeño Max, испанская раскраска. Записка для продолжения работы

## Что это за задача

У Рикардо есть две испанские раскраски на Amazon KDP:

- **El Primer Libro de Colorear** (сиреневая обложка, львенок) - продается хорошо
- **Pequeño Max** (синяя обложка, мышонок Макс) - в поиске и в ChatGPT выходит первой, но не продается

Причина в содержании. Книга обещает малыша 1-3 лет, а внутри лежат нитки, иголка, пуговицы,
ножницы, конверт, расческа, мельница, маяк, забор, скамейка. Для ребенка этого возраста это
чужие вещи. Плюс в испанских подписях были прямые ошибки: утенок подписан **Ganso** (гусь),
перо подписано **Pero** (означает "но"), домик - **Hogar** (домашний очаг), бантик - **Arco** (арка),
фонарь на столбе и фонарик оба **Linterna**, курица - **Pollo** (курятина), кролик - **Liebre** (заяц).

**Решение:** полностью заменить содержимое книги и обложку. Название и мышонок Макс остаются.
Число страниц остается 114, чтобы толщина корешка не изменилась и старый шаблон обложки подошел.
Карточка на Amazon та же, новый ISBN не нужен.

## Как выбирался состав

Не на глаз. Взят опросник **MacArthur-Bates CDI** - научный список слов, которыми пользуются дети
8-30 месяцев, по которому логопеды во всем мире измеряют словарь малыша. Использована
**европейская испанская версия** (López Ornat и др., 2005), потому что книга со львенком тоже
на классическом испанском и обе книги должны быть одной серией.

Проверено также, как устроен лидер продаж в этой нише на Amazon (The Creative Toddler's First
Coloring Book Ages 1-3): простые знакомые картинки из повседневных предметов, фруктов и овощей,
лесных, домашних животных и животных зоопарка.

Правила от специалистов по детским раскраскам: один-два крупных простых объекта на страницу,
минимум текста, узкий возрастной диапазон, жирные контуры до 2-3 мм.

**Правило отбора рисунка:** если в фигуре больше восьми участков для закрашивания, она не для
1-3 лет. По этому правилу отложены сказочные персонажи (Красная Шапочка, принц, принцесса,
рыцарь, Золушка, пряничный домик, гном) - из них потом можно сделать отдельную книгу для 3-5 лет.

Полный состав из 111 позиций - в файле **SPISOK-111.md**, в порядке страниц.

## Исходные рисунки

Все рисунки Рикардо нарисовал сам, по шесть на листе, без подписей (книга будет на двух языках).
Исходные листы лежат в `listy-ishodnye/`: файлы `01.png` - `09.png`, `010.png`, `011.png`,
`012.png` плюс более ранние листы с именами из шестнадцатеричных букв.

Отдельные рисунки в архив не клались, чтобы не раздувать число файлов. Их создаёт скрипт
`kod/narezka.py`: положить его рядом с папкой `listy-ishodnye` и запустить, он сделает папку
`risunki-narezannye` со **165 отдельными рисунками**. Результат проверен, совпадает
с исходной нарезкой файл в файл.
Из них в книгу идет 111, остальные 54 - запас (кит, акула, скат, медуза, морской конек, морская
звезда, петух, лебедь, аист, павлин, попугай, носорог, ежик, енот, волк, пицца, суп, бургер,
пончик, кекс, стульчик, рюкзак, ножницы, радуга, зубная паста, стаканчик с карандашами и сказочные
персонажи).

**Важно:** нумерация рисунков менялась по ходу работы, потому что файлы добавлялись. Не полагаться
на номера из переписки, брать соответствие только из `kod/book.json`.

## Технические условия рукописи

Сняты измерениями с книги со львенком, не из головы.

| параметр | значение |
|---|---|
| формат | 8,5 x 11 дюймов и отдельно A4 (8,268 x 11,693) |
| страниц | ровно 114 |
| разрешение | 314 точек на дюйм |
| поля со всех сторон | 0,95 дюйма (Amazon требует у корешка 0,5, запас есть) |
| толщина линии рисунка | 28 точек = 2,26 мм |
| поле под рисунок | по вертикали 1,00 - 8,10 дюйма, для двустрочной подписи 1,00 - 7,75 |
| полоса подписи | 8,40 - 9,75 дюйма, для двустрочной 8,05 - 9,80 |
| шрифт подписи | Nunito, начертание 900 |
| толщина обводки буквы | 24 точки, чуть тоньше линии рисунка |
| буквы | полые внутри, ребенок может их раскрасить |

Структура книги: титульный лист, страница "Este libro pertenece a", 111 рисунков с подписями,
копирайт в конце.

## Две ловушки, на которые уже наступали

**1. Измерение толщины линии.** Нельзя мерить по распределению расстояний внутри чернил: сплошные
залитые пятна (полоски тигра и зебры, зрачки) дают огромные значения, и рисунок потом уродуется
эрозией. Мерить надо **медиану ширины вдоль средней линии фигуры** (скелет). Готовая функция -
`stroke_of` в `kod/clean.py`.

**2. Изменение толщины линии.** Нельзя двигать толщину обычной морфологией с целым числом шагов,
края становятся рваными (на тигре это было хорошо видно). Надо считать расстояние до границы
и менять толщину плавно, работая с двойным запасом по размеру и потом сглаживая. Готовая функция -
`smooth_thickness` в `kod/build2.py`.

**3. Обрывки соседних рисунков.** При нарезке листов на края кадра попадают кусочки соседних
фигур. Убирать надо только мелкие куски, прилипшие к краю кадра. Нельзя убирать все, что вне рамки
главной фигуры: так пропадают мыльные пузыри, летящие рядом с баночкой. Готовая функция -
`clean_ink` в `kod/clean.py`.

## Испанские слова

Взяты из европейского испанского опросника, не переведены самостоятельно. Заодно исправлены две
ошибки, тянувшиеся из книги со львенком:

- вишня: было **Guinda** (это кислая вишня, морель), стало **Cereza**
- торт: было **Torta** (в Мексике это вообще бутерброд), стало **Pastel**

В книге со львенком остаются еще две неисправленные ошибки, которые пропустил переводчик:
сосновая шишка подписана **Chichón** (это шишка на лбу от удара), геймпад подписан английским
словом **Gamepads**. Это к отдельной задаче по книге со львенком.

## Что осталось сделать

1. Досборка PDF в двух форматах (код готов, см. ниже)
2. Обложка с мышонком Максом. Формат обложки менять нельзя, Amazon не примет
3. Титульный лист и короткое оглавление - Рикардо хотел обсудить отдельно
4. Роль Макса: он герой, который в описании показывает своих друзей ребятам. Придумать отдельно
5. Потом то же самое для английской версии книги

## Как запустить сборку

```
python3 run.py 0 114      # собирает страницы в папку pages2
```
Дальше страницы складываются в PDF через PyMuPDF: страница нужного размера в дюймах на 72,
картинка вставляется на весь лист.

Нужны библиотеки: pillow, numpy, scipy, scikit-image, pymupdf.
Шрифт Nunito берется из пакета `@fontsource/nunito` через `npm pack`, файлы там в формате woff2,
перегоняются в ttf через fontTools.

## Как работать с Рикардо

- Только по-русски, без буквы ё и без длинных тире
- Никаких технических вопросов и выбора между техническими вариантами. Решать самому
- Спрашивать только про смысл, замысел и то, что видит читатель
- Объяснять обычными словами, без терминов
- Ответы короткие. Длинные утомляют
- Английский текст ему не показывать, он его не читает
- Перед изменением файлов спрашивать разрешение. Перед чтением не надо
- Не увязать в мелочах. Показывать результат, а не процесс
